Las tres formas de integrar CSS

CSS define la presentación visual de una página: colores, tipografía, espacios y distribución. Puede incorporarse de tres maneras.

1. CSS en línea

La regla se escribe en el atributo style de una etiqueta. Solo afecta ese elemento.

<h1 style="color: #275139;">Nativa Energía</h1>

Es útil para una excepción puntual, pero mezcla el contenido con su presentación y dificulta mantener un diseño uniforme.

2. CSS interno

Las reglas se escriben dentro de <style> en el <head> del documento. Aplican a esa página.

<style> h1 { color: #275139; } </style>

Puede servir para una página aislada, pero habría que repetir o sincronizar las reglas en cada página del sitio.

3. CSS externo

El HTML enlaza un archivo independiente con las reglas de estilo.

<link rel="stylesheet" href="css/estilos.css">

La regla, por ejemplo, se escribe en css/estilos.css:

h1 { color: #275139; }

¿Por qué Nativa Energía usa CSS externo?

El sitio tiene cuatro páginas —Inicio, Catálogo, Nosotros y Contacto—, todas enlazan la misma hoja css/estilos.css. El enlace se ubica después de Bootstrap para que los estilos propios puedan personalizar sus componentes. Así se mantiene una identidad consistente, se separan estructura y presentación, y un cambio de diseño se hace en un solo archivo.
